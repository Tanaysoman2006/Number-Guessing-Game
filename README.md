# Number Guessing Game (Python)

A simple console-based Python game where the user tries to guess a randomly generated number.  
The program provides hints until the correct number is guessed.

## Project Objective
To understand basic Python concepts such as loops, conditionals, user input handling, and the use of built-in modules.

## Features
- Generates a random number within a defined range
- Takes user input from the console
- Provides feedback (Too High / Too Low)
- Continues until the correct number is guessed

## Technologies Used
- Python 3
- random module

## How It Works
1. The program generates a random number between 1 and 100.
2. The user enters a guess.
3. The program compares the guess with the generated number.
4. Hints are shown until the user guesses correctly.
